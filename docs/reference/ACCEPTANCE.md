- 实际SDK输入：每眼1278×360 RGB；SBS2556×360，视频FPS上限60。

- saturation=1、gamma=1、正常眼序；没有红蓝诊断标记。
- NVENC/WebRTC视频与WebRTC姿态独立连接；同一个XRSession/GL上下文。
